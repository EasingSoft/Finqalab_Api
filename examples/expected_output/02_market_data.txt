Expected output for examples/02_market_data.py
==============================================

Figures are real, taken from a live session on a normal trading day. They move
constantly, so treat the shape as the contract and the numbers as a sample.

$ export FQ_USER_ID=00000
$ export FQ_PASSWORD='your-password'
$ python examples/02_market_data.py

The payload is richer than the four columns printed here. Each index also
carries volume, value_change, percent_change, bid/ask, and a `lt` field that
is itself a JSON string of the live tick:

    "lt": "{\"t\":1786618185,\"x\":180104.6112,\"v\":4114}"

One call returns every listed symbol - roughly 430 KB of JSON. There is no
pagination parameter; filter client-side.

Each row is a finqalab.models.Snapshot:

    Symbol name sector Open High Low Price Change PercentChange
    Volume Bid Ask listed_in raw

`sector` is a numeric code (e.g. "0824" for Oil & Gas), not a label. `listed_in`
is a list such as ["ALLSHR "].

Notes
-----
* Every call here only needs a valid token. No trading socket required.
* index_news() and summary() return numbers as strings for some fields and
  numbers for others - the raw dict is preserved in `.raw` if that matters.
* statistics() defaults date to today, which on a weekend or holiday returns
  the previous session's data.
